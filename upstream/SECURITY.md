# Security Policy

## Supported Versions

| Version | Supported          |
| :---    | :---:              |
| Latest  | :white_check_mark: |
| < Latest | :x:               |

## Reporting a Vulnerability

We take the security of our project and users seriously.

If you discover a security vulnerability:

1. **Do not disclose it publicly** in an issue, discussion, or pull request.
2. Email your findings directly to `security@example.com`.
3. Include:
   - A detailed description of the vulnerability and its potential impact.
   - Step-by-step reproduction instructions or a minimal proof-of-concept.
   - Any affected versions and environment details.

Maintainers will acknowledge receipt of your vulnerability report within 48 hours and work with you on a coordinated fix.
