# Code review guidance

Review in this order:

1. Correctness and whether the change satisfies the stated intent.
2. Regressions, edge cases, and error handling.
3. Security, privacy, permissions, and secret handling.
4. Tests and whether they verify observable behavior.
5. Documentation, compatibility, and maintainability.

Prioritize actionable findings. Distinguish confirmed defects from questions or suggestions.
