# Contributing Guidelines

Thank you for contributing! We welcome community contributions, bug reports, and suggestions.

## Code of Conduct

All contributors and maintainers are expected to adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).

## Getting Started

1. Check the repository Issues page for open tasks or bug reports.
2. Look for issues labeled `good first issue` or `help wanted`.
3. Comment on the issue you would like to work on before starting to coordinate with maintainers.

## Pull Request Guidelines

1. **Branch Naming**: Use a descriptive branch prefix such as `feat/`, `fix/`, `docs/`, or `chore/`.
2. **Commit Messages**: Write clear, descriptive commit messages.
3. **Focused Changes**: Keep pull requests focused on a single change or feature.
4. **Testing**: Run tests locally and add test coverage for bug fixes or new functionality.
5. **Documentation**: Update documentation whenever behavior or configuration changes.

## Developer Certificate of Origin (DCO)

If required by this repository, sign off on your commits:
```bash
git commit -s -m "feat(core): add feature description"
```

## Contact & Questions

If you have questions, please reach out via:

- Security inquiries: `security@example.com`
