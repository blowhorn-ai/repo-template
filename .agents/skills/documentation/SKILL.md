# Documentation guidance

1. Identify the canonical owner for the information before editing.
2. Keep the README concise; place detailed guides in the documentation directory.
3. Avoid duplicating configuration tables or examples across multiple documents.
4. Update links and examples when behavior or commands change.
5. Do not claim a feature or command exists unless verified in the repository.
