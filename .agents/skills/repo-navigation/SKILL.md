# Repository navigation

1. Read `README.md`, `AGENTS.md`, and the relevant package manifests.
2. Identify the application entry points and the owner of the behavior being changed.
3. Inspect nearby tests and documentation before editing.
4. Avoid broad refactors when a focused change is sufficient.
5. Update this repository's `AGENTS.md` only when its existing facts become inaccurate.
