# Contributing to Blowhorn AI

Thank you for your interest in contributing to Blowhorn AI! We welcome community contributions, bug reports, and suggestions.

## Code of Conduct

All contributors and maintainers are expected to adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).

## Getting Started

1. Check the [Issues](https://github.com/blowhorn-ai/repo-template/issues) page for existing tasks or bug reports.
2. Look for issues labeled [`good first issue`](https://github.com/blowhorn-ai/repo-template/labels/good%20first%20issue) or [`help wanted`](https://github.com/blowhorn-ai/repo-template/labels/help%20wanted).
3. Comment on the issue you would like to work on before starting to ensure coordination.

## Pull Request Guidelines

1. **Branch Naming**: Use a descriptive branch prefix such as `feat/`, `fix/`, `docs/`, or `chore/` (e.g. `feat/user-auth`, `fix/login-crash`).
2. **Commit Messages**: Write clear, descriptive commit messages.
3. **Keep Changes Focused**: Each pull request should address a single concern or feature.
4. **Testing**: Run tests locally and add test coverage for bug fixes or new functionality.
5. **Documentation**: Update relevant documentation when adding features or altering configuration.

## Developer Certificate of Origin (DCO) & Sign-Off

To ensure legal clarity for open source contributions, commits may require Developer Certificate of Origin sign-off:
```bash
git commit -s -m "feat(core): add feature description"
```
The `-s` flag appends `Signed-off-by: Your Name <your.email@example.com>` to the commit message.
