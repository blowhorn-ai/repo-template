# Security Policy

## Supported Versions

| Version | Supported          |
| :---    | :---:              |
| Latest  | :white_check_mark: |
| < Latest | :x:               |

## Reporting a Vulnerability

Blowhorn AI takes the security of our software and users seriously.

If you discover a security vulnerability in this project:

1. **Do not disclose it publicly** in an issue, discussion, or pull request.
2. Email your findings directly to `security@blowhorn.ai`.
3. Include:
   - A detailed description of the vulnerability and its potential impact.
   - Step-by-step reproduction instructions or a minimal proof-of-concept.
   - Any affected versions and environment details.

Our team will acknowledge receipt of your vulnerability report within 48 hours and work with you on a coordinated fix.
